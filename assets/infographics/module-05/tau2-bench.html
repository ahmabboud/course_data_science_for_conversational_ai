Can AI agents talk you through the fix?

τ²-bench tests AI support agents when the customer must press the buttons too.

5 min read Benchmark study Barres et al., 2025 · τ²-bench
1

The big idea in one sentence

The same AI agent solves far fewer problems the moment a real user has to act too, not just talk.

Step 1 · Question

What did they want to know?

?

How do agents cope when the user shares control?

In τ-bench only the agent could act. The user just talked.

Step 2 · Key ideas

Three ideas you need first

Dual control

Agent and user both use tools on one shared world.

Like: tech support talking you through a phone reset.

No-user mode

A test where the agent does every step alone, no chat.

Like: a solo dry run before the real thing.

Default mode

The normal test: agent must guide a real user.

Like: the actual support call.

Step 4 · Method

How they tested it

  1. Build

    Telecom: records plus user's phone.

  2. Generate

    114 tasks from 2,285 combos.

  3. Role play

    GPT-4.1 plays the customer.

  4. Grade

    Is the phone fixed? 4 runs.

Step 5 · Why it matters

Every extra step hurts

Keep in mind

  • 1 new domain: telecom support only.
  • Fake users: still err in 16% of chats.
  • No expert vs novice gap modeled yet.
  • 4 models, early 2025: newer may differ.
  • Guiding someone is harder than doing it yourself.
  • Every extra step compounds the chance of failure.
  • Test agents with a real user in the loop, not just alone.
Oracle plan
The agent is handed the exact list of correct steps.
User persona
A short profile of the fake customer, like "low tech knowledge".
Critical error
A fake user mistake that makes the task impossible to finish.
