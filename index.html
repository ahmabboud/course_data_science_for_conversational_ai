Five modules, one project

18 contact hours · 5 modules of 3 hours, plus a 3-hour project defense · MSc. LLM-only: no classical NLP stack. Every team grows one conversational agent from Module 1 onward, in its own domain, one GitHub issue per module. The defense in Module 6 is a live demonstration of that same system.

Module 01 Foundations and Modern Understanding The reference architecture, why function calling replaces classical intent and entity extraction, and the project kickoff. 180 min · 28 slides Module 02 Agentic Dialogue Management The raw agent loop, then LangGraph with explicit state, MCP for tools, and one routing or escalation pattern. 180 min · 21 slides Module 03 Grounded Generation RAG with hybrid search and reranking as the default, cache-augmented generation as a comparison. Not yet built Module 04 Memory Session memory and persistent, cross-session memory, and what persistent memory costs in privacy risk. Not yet built Module 05 Evaluation and Responsible Deployment Multi-turn evaluation, the blind spots of LLM-as-judge grading, bias and PII probes, deployment concerns. Not yet built Module 06 Project Defense Live demonstration, scorecard, and architecture defense of the same system grown since Module 1. No lecture deck

How to use a lecture

Teaching

Open the lecture, press F for fullscreen and P for presenter view on your second screen. T starts the session timer; the pacing readout tells you whether you are behind the plan.

Studying

Press S. Every definition becomes an inline note, every held-back answer opens, and your position and answers are remembered on your own device. / searches the whole lecture.

Offline and on paper

Install the site from your browser's address bar and lectures you have opened work without a network. Handout in the bottom bar prints one page per slide with the notes attached.
