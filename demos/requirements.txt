# Instructor-side dependencies shared by every demo in this folder. Separate
# from any team's own requirements.txt in their project repository.
#
# google-genai must be at least 2.3.0: the Interactions API this course's
# code calls (client.interactions.create) does not exist on older 1.x
# releases, and a bare ">=1.0" floor let pip resolve to one of those and
# fail at runtime with "'Client' object has no attribute 'interactions'".
#
# langgraph-cli needs Python 3.10 or newer (module-02's demo). Check
# `python3 --version` before installing here if your environment predates
# that: see module-02/README.md and this folder's own README.md for the
# exact setup and how to run each module's demo.
#
# rank_bm25 and numpy are module-03's demo: a pure-Python BM25 index and
# the vector math for cosine similarity against Gemini embeddings. Neither
# needs a real vector database or a cross-encoder model, see
# module-03/README.md for why reranking uses one more Gemini call instead
# of a dedicated reranker model.
#
# mem0ai is module-04's demo. Pinned to 2.0.20 or newer, the verified
# release as of this writing, because the filters-based user_id contract
# on search/get_all documented in module-04/README.md is the one this
# course's code relies on; do not lower this floor without re-checking
# that contract still holds. Its own dependency on qdrant-client brings in
# Qdrant's embedded, on-disk mode, no separate server or install needed.
# nbformat and nbconvert execute and save Module 4's self-study notebook
# with its checked output, using the same shared demo environment.
#
# Module 5's evaluation harness needs no new package: it reuses
# google-genai (its toy agent and judge calls) and mem0ai (its PII probe,
# importing module-04/memory_demo.py's own functions directly).
